
# SauceDemo Playwright Automation

End-to-end UI automation using JavaScript, Playwright Test,
and the Page Object Model (POM).

## Prerequisites

- Node.js LTS
- npm
- Git

## Installation

```bash
npm install
npx playwright install chromium
```

## Run API Test for https://petstore.swagger.io/v2
```bash
npm run test:api
```

## Run all tests

```bash
npm test
```

## Run tests with the browser visible

```bash
npm run test:headed
```

## Run individual test suites

```bash
npm run test:login
npm run test:checkout
```

## Open HTML report

```bash
npm run report
```

## Test scenarios

1. Successful login
2. Complete checkout for Sauce Labs Onesie

## Technology

- JavaScript
- Playwright Test
- Page Object Model
- Git
